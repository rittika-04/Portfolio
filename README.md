## Run locally

### Prerequisites

- Node.js and npm

### Setup

```bash
git clone https://github.com/rittika-04/Portfolio.git
cd Portfolio
npm install
npm run dev
```

Open the local URL printed by Next.js in your terminal.

## Production build

```bash
npm run build
npm start
```
